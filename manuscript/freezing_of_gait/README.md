# Freezing of gait (FOG)

[Manuscript index](../README.md) · [NNDR user documentation](../../docs/quickstart.md)

## Scope

Historical methodology from the original manuscript. Full revised cohort numerical reproduction is not provided here.

## Data and analysis

[Daphnet Freezing of Gait](https://archive.ics.uci.edu/dataset/245/daphnet+freezing+of+gait), three ankle acceleration axes. Original representative event `S01R01`, event 03, 1236.0–1245.6 s; first 4 s of freezing used as onset interval. Original windows 3 s, step 0.5 s; compare onset with matched non-freezing baseline and distinguish sustained freezing and gait re-initiation. The revised supplementary analyses are not bundled.

For new analyses, specify preprocessing, sampling interval, ridge and admissibility rules. Original cohort counts and settings are historical descriptors, not newly verified revised results.
