# Interpretation, limitations and compatibility

[Documentation](index.md) · [API](api_reference.md) · [Reproducibility](../manuscript/README.md)

- **Local model:** the estimator is a homogeneous one-step linear predictor, not necessarily the physical Jacobian. Nonstationarity, observation noise, omitted variables, delays, nonlinear dependence and preprocessing may change the result. A two-dimensional compression need not be invariant.
- **Coordinates:** non-normality depends on the Euclidean metric. Uniform scaling is compatible with relative ridge; per-channel scaling changes that metric. Use finite real data; the high-level validators reject complex arrays. Supply at least two channels and enough observed pairs. Rank deficiency is not resolved scientifically by ridge alone.
- **Sampling:** use actual `dt`; the principal log cannot distinguish aliased oscillations. Negative or zero real multipliers invalidate R_A, not necessarily R_sigma. Full and reduced stability must both be reported. Shrinkage is not a stability guarantee.
- **Geometry:** M2 uses seeded alternating optimization, with no global certificate. M1 can be ill-conditioned; M3 plane and direction flags are numerical checks. No analogous full identifiability flags are provided for M1/M2. Agreement between methods on a common fitted operator checks extraction sensitivity only.
- **Windows:** overlapping windows are dependent. `t_end` is an exclusive sample boundary. The default rolling API does not center locally or catch all fitting exceptions. Zero-phase preprocessing uses future samples, even when window timestamps are trailing. This is not automatically a prospective predictor.
- **Statistical controls:** the default portmanteau reference is not adjusted for selected planes; phase-only surrogates preserve cross-periodograms but not marginal distributions; stationary normal references match total variance in expectation, not local envelopes or individual channel variances. Default Schur ordering differs from modulus-ordered Schur. Branch unwrapping is 2D and reference-guided, not integrated into ambient lag consistency. Bootstrap coverage and cutoff calibration are application-specific. Fit preprocessing on training data only for prospective prediction. Do not infer universal adequacy or clinical significance from a p-value or ratio crossing.
- **Historical comparisons:** `threshold='legacy'` deliberately retains historical definitions. Default support is L1, while the frozen seizure plots use entropy support and multiplier splitting. The earlier synthetic benchmark uses raw commutator basis support; do not interpret that column as ordered reaction support. Historical `best_plane_corr` is a heuristic; use `plane_correlation` for the exact least-squares alignment. The EDF reference adapter is a separately validated historical workflow with multistart M2, not the generic default API.
- **Scope:** two revised synthetic benchmarks and one representative EEG recording have executable reproduction. The larger EEG cohort, EHG, FOG and push-up analyses are described but are not claimed to be fully reproduced by this release. See the consolidated guide. No causal or clinical claim follows from a numerical reproduction.

For scientific reporting, record preprocessing and scaling, dimensions, sample interval, window/step, ridge and shrinkage, extraction seeds, spectral and directional flags, missing fractions, statistical calibration and exact code commit. Keep derived reference data separate from newly computed outputs. A failure to reproduce a reference is a result to investigate, not a reason to tune against the event.
