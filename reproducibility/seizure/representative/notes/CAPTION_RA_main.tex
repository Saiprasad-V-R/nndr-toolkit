\caption{Representative moving-window diagnostics for the annotated seizure in CHB-MIT recording \texttt{chb01\_03.edf} (2996--3036\,s). (a) Mean field of the fixed 16-channel bipolar EEG montage, in \(\mu\mathrm V\). (b) Corrected continuous-time response ratio \(R_A\) from the optimization plane (M2, orange) and commutator plane (M3, green). (c) Normalized entropy-based support of the reaction direction, \(\exp[-\sum_i p_i\log p_i]/16\), where \(p_i=\hat r_i^2/\sum_j\hat r_j^2\). (d) Reduced eigenvalue splitting \(\Delta=|\lambda_1-\lambda_2|/|\lambda_1+\lambda_2|\) for the projected 2D operator. Diagnostics use 40-s trailing windows advanced by 2\,s; horizontal positions mark window ends relative to seizure onset. Thin translucent curves show unsmoothed window values; thick curves show a five-endpoint centered median computed only within uninterrupted valid segments. Gray shading and dashed boundaries mark the verified 40-s seizure. The dashed line in (b) marks \(R_A=1\), the corrected reduced-model response threshold. The ratio axis is linear and displayed from 0 to 4; larger saved values are outside the displayed range. Invalid ratios remain gaps. This representative recording is descriptive and does not establish seizure prediction.}
