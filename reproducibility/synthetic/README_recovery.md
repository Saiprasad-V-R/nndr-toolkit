# Synthetic validation II: recovery from stochastic trajectories

This is a new controlled demonstration of finite-data inference, not an exact reproduction of a numbered figure in the original preprint. The [exact threshold experiment](README.md) validates the mathematics separately.

## Run

From an activated environment in the repository root:

```sh
python -m pip install -e '.[dev]'
python -W error::RuntimeWarning reproducibility/synthetic/validate_recovery.py --out results/synthetic/recovery
```

For the validated Apple Silicon Python 3.9 environment use NumPy 1.26.4 and SciPy 1.13.1 as in `requirements-validated-macos.txt`. `--reps 2` is a quick smoke test; the default 12 is the reported benchmark. All randomness is seeded. Outputs are `recovery_trials.csv`, `recovery_summary.csv`, `recovery_summary.json`, `recovery_benchmark.png`, `recovery_benchmark.svg`.

## Callable generators

```python
from nndr.synthetic import complex_generator
from nndr.synthetic_recovery import embedded_map, simulate_trajectory
from nndr import analyze_operator
from nndr.ridge import ridge_fit_F

L = complex_generator(gamma=1., omega=2., K=1.5)
F, Q_true = embedded_map(L, dimension=12, dt=0.1, seed=1)
X = simulate_trajectory(F, samples=5000, noise_std=0.1, seed=2)
X0, Y = X[:, :-1], X[:, 1:]
lam = 1e-6 * (X0**2).sum() / X0.shape[0]
Fhat = ridge_fit_F(X0, Y, lam)
res = analyze_operator(Fhat, method='M3', dt=0.1)
print(res.R_A, res.R_sigma, res.support)
```

`embedded_map` requires a real, stable 2-D continuous-time generator and unaliased sampling. An orthogonal similarity embeds its sampled block alongside stable real normal background modes. `simulate_trajectory` returns channels by samples after discarding a burn-in, with per-step isotropic innovations; it does not model measurement noise or continuous-time diffusion.

## Design and comparison

- N=12, dt=0.1; real rates 0.5 and 2, complex decay 1 and angular frequency 2. Ten background rates evenly spaced from 1.2 to 1.8. Orthogonal embeddings generated by sign-corrected QR of seeded Gaussian matrices.
- Four target R_A values (0.25, 0.65, 1.35, 2.0) per spectrum, selected analytically; these cover both sides of both thresholds. R_sigma ground-truth class is verified from the exact block singular value. Twelve independent realizations per cell. Innovations SD 0.1 per step, 500 discarded steps. Nested prefixes of 200, 1000 and 5000 observed states, and a separate 2000-sample trajectory for observable analysis.
- Ridge regression on observed adjacent pairs only; fixed relative regularization lambda=1e-6 * trace(X0 X0^T)/N. No model selection, stability rescaling or clipping. This deliberately controlled benchmark does not reproduce the original cross-validation design. All methods use precisely the same Fhat at each sample length; M2 uses its existing default 250 iterations and seed 0.
- Four stages in the raw table: truth (true F, true Q), oracle (true F, extracted Q), known_plane (estimated F, true Q), estimated (estimated F, extracted Q). The last stage gives 864 method/length/realization rows; 1536 rows overall. Nested sample sizes are not independent replicates.
- Errors: largest principal angle (degrees); absolute errors in R_A, R_sigma, K, and splitting (only if spectral family matches); relative Frobenius operator error; reduced/full stability; finite ratio validity; one-step capture fraction; support; and absolute error in mean-field alignment. Invalid ratio estimates are excluded from finite-error quantiles, but counted as incorrect in unconditional classification fractions. The raw table retains them as NaN; spectrum mismatch is explicit. No threshold-boundary cases are targeted.
- Mean-field alignment is the exact maximum absolute correlation obtained by least-squares projection onto the centered coordinates of Q, evaluated on the independent test trajectory. It is a descriptive alignment on that trajectory, not held-out predictive skill. The existing `best_plane_corr` heuristic does not generally attain this maximum; do not confuse the two. A public corrected observable function is deferred to the scientific API phase.
- Support follows the existing high-level result's Q[:,0] convention. It is basis dependent and not a plane-invariant recovery target; there is no unique reference reaction direction for the embedded plane. Existing M3 direction names and Q column order disagree; this benchmark intentionally does not change the extraction method.
- Plots show median and interquartile range of finite errors over all four target values and seeds, separately by spectral family. Classification fractions, validity and other metrics are in the summary tables. M1 remains a baseline; a poor estimated-plane result is not discarded.

## Limitations

These results are conditional on the chosen spectral families, dimension, noise model, ridge strength and sample lengths. No claim of universal recovery, monotonic convergence for every realization, or causal inference is made. An exact oracle plane does not guarantee finite-data recovery. This test does not cover measurement noise, nonlinear systems, nonstationarity or the empirical EEG/push-up pipelines.
